隱私權政策

LINE 會議摘要．最後更新：2026 年 11 月 1 日

適用範圍

LINE 會議摘要是個人自用工具，只有擁有者本人使用，不對外提供服務，也沒有其他使用者。

讀取哪些資料

  • LINE 訊息：擁有者本人 LINE 帳號裡的聊天訊息（擁有者設定排除的聊天室與官方帳號除外），用來找出約定的會議與行程。
  • Google 日曆：只使用 calendar.app.created 權限，也就是只能讀寫本工具自己建立的子行事曆「LINE 擷取」。本工具看不到、也不能修改擁有者的其他行事曆。

資料怎麼處理與存放

  • 程式在擁有者自己的電腦上執行，訊息與判斷結果存在那台電腦的本機資料庫，保留 90 天後自動刪除。
  • 判斷行程主要使用同一台電腦上的地端 AI 模型，訊息不會離開這台電腦。
  • 地端模型無法使用時，該段對話會透過 API 送到 Anthropic（Claude）判斷行程，依 Anthropic 的商業服務條款處理，不會被用來訓練模型。
  • 寫進「LINE 擷取」行事曆的只有行程標題、時間、地點與一句摘要，不含訊息原文。
  • 登入憑證以加密方式存放在擁有者電腦的系統保管區（macOS 鑰匙圈）。

分享

本工具不會出售、出租或分享任何資料給第三方，也不用於廣告。除上述 AI 判斷外，不會把資料傳送到其他地方。

本工具使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

撤銷授權

擁有者可以隨時到 Google 帳戶的第三方存取權頁面 撤銷本工具的日曆權限；撤銷後本工具無法再讀寫「LINE 擷取」行事曆。
